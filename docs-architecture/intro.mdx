### 2. Software Architecture & Modeling

- **C4PlantUML** (`1.2026.6`) – PlantUML macros and extensions for rendering the C4 software architecture model.
- **Structurizr** (`6.2.2`) – Tooling for visualizing and documenting software architecture based on the C4 model.
- **Nomnoml** (`1.7.0`) – Lightweight tool for drawing UML class diagrams from simple grammar.
