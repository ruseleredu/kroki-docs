# Hardware

Hardware, Timing & Protocol diagramming tools.

This section contains documentation and resources for tools in the **Hardware** domain.

## WaveDrom

**ID:** wavedrom

**Description:** JavaScript/JSON-based digital timing diagram rendering engine.

- [Official Site](https://wavedrom.com/)
- [Documentation](https://wavedrom.com/tutorial.html)
- [Source Code](https://github.com/wavedrom/wavedrom)
- [Online Editor](https://wavedrom.com/editor.html)
- [Samples](https://wavedrom.com/tutorial.html)

## Bytefield

**ID:** bytefield

**Description:** Tool for generating network protocol and memory layout packet diagrams.

- [Official Site](https://bytefield-svg.deepsymmetry.org/bytefield-svg/intro.html)
- [Documentation](https://bytefield-svg.deepsymmetry.org/bytefield-svg/intro.html)
- [Source Code](https://github.com/Deep-Symmetry/bytefield-svg/)
- [Online Editor](https://github.com/Deep-Symmetry/bytefield-svg)
- [Samples](https://bytefield-svg.deepsymmetry.org/bytefield-svg/examples.html)
