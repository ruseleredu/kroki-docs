### 5. Hardware, Timing & Protocols

- **WaveDrom** (`3.6.1`) – JavaScript/JSON-based digital timing diagram rendering engine.
- **Bytefield** (`1.11.0`) – Tool for generating network protocol and memory layout packet diagrams.
- **Symbolator** (`1.2.2`) – Schematic symbol generator from HDL (Hardware Description Language) code.
