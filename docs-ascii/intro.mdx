# ASCII & Tools

ASCII Art, Text-to-SVG converters, and ecosystem aggregators.

This section contains documentation and resources for tools in the **ASCII & Tools** domain.

## Ditaa

**ID:** ditaa

**Description:** Converts ASCII art text diagrams into clean vector graphics.

- [Official Site](https://ditaa.sourceforge.net/)
- [Documentation](http://ditaa.sourceforge.net)
- [Source Code](https://sourceforge.net/p/ditaa/svn/HEAD/tree/)
- [Online Editor](https://ditaa.sourceforge.net/)
- [Samples](https://ditaa.sourceforge.net/)
