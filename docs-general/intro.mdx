### 1. General-Purpose & Multi-Paradigm Diagramming

- **Mermaid** (`11.15.0`) – Markdown-inspired syntax for generating flowcharts, sequence diagrams, and charts.
- **PlantUML** (`1.2026.6`) – Text-based language for creating UML diagrams and system architectures.
- **Graphviz / DOT** (`14.1.3`) – Open-source graph visualization software using the DOT language.
- **D2** (`0.7.1`) – Modern, declarative diagram scripting language.
- **Diagrams.net** (`16.2.4`) – Open-source visual diagram editor engine (Draw.io).
- **Excalidraw** (`0.18.1`) – Virtual whiteboard tool for hand-drawn, sketch-style diagrams.
- **UMlet** (`15.1`) – Free, interactive UML diagram drawing tool.
- **TikZ** (`3.1.9a`) – Programmatic graphics package for TeX/LaTeX.
