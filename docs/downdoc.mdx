## downdoc: Down-convert AsciiDoc to Markdown

The downdoc package provides both a CLI (command: downdoc) and a JavaScript function (downdoc) to down-convert AsciiDoc to Markdown.

- https://github.com/opendevise/downdoc
- https://app.mdedit.ai/tools/converter/asciidoc-to-markdown

## Migrating

Migrating from **Antora** (which uses **AsciiDoc** and a multi-repo/component structure) to **Docusaurus** (which uses **Markdown/MDX** and a React-based single-repo architecture) requires handling three main differences:

1. **Markup Language:** Converting `.adoc` (AsciiDoc) files to `.md` or `.mdx` (Markdown).
2. **Navigation & Structure:** Translating Antora's `nav.adoc` files and `antora.yml` component descriptors into Docusaurus's sidebar configurations (`sidebars.ts`) and flat/nested folder hierarchies.
3. **Cross-References & Attributes:** Replacing Antora-specific macros (`xref`, `include`, block attributes) with standard Markdown equivalents or Docusaurus plugins.

---

### Step 1: Initialize a New Docusaurus Project

If you haven't already set up your Docusaurus site, create one using the classic template:

```bash
npx create-docusaurus@latest my-docs classic --typescript
cd my-docs
npm start
```

---

### Step 2: Convert AsciiDoc (`.adoc`) to Markdown (`.md` / `.mdx`)

Because syntax differs, you need to translate your source files. For small to medium sites, an automated script (using Python or Node.js with regex) or manual conversion works best. For large enterprise codebases, tools like `pandoc` can assist with the bulk syntax translation.

#### Syntax Mapping Quick Reference:

| Element              | Antora (AsciiDoc)                                       | Docusaurus (Markdown / MDX)                       |
| -------------------- | ------------------------------------------------------- | ------------------------------------------------- |
| **Page Title**       | `= Document Title`                                      | `# Document Title` (or via Front Matter `title:`) |
| **Headings**         | `== Section Title`                                      | `## Section Title`                                |
| **Bold / Italic**    | `*bold*`, `_italic_`                                    | `**bold**`, `*italic*`                            |
| **Links**            | `[https://example.com](https://example.com)[Link Text]` | `[Link Text](https://example.com)`                |
| **Cross-References** | `xref:page-name.adoc[Link Text]`                        | `[Link Text](./page-name.md)`                     |

---

### Step 3: Reorganize Directory Structure

Antora structures content by **components** and **modules** (`modules/ROOT/pages/`). Docusaurus relies directly on a centralized `docs/` folder hierarchy.

**Antora structure:**

```text
my-component/
├── antora.yml
└── modules/
    └── ROOT/
        ├── nav.adoc
        └── pages/
            ├── index.adoc
            └── guide/
                └── intro.adoc

```

**Target Docusaurus structure:**

```text
my-docs/
└── docs/
    ├── index.md
    └── guide/
        └── intro.md

```

_Tip: Flatten your Antora module directories (`modules/ROOT/pages/`) directly into the Docusaurus `docs/` folder tree._

---

### Step 4: Map Navigation (`nav.adoc` to `sidebars.ts`)

Antora uses an AsciiDoc list inside `nav.adoc` to build menus. Docusaurus manages this via `sidebars.ts` in the root directory.

#### Example conversion:

**Antora (`nav.adoc`):**

```asciidoc
* xref:index.adoc[Home]
* Getting Started
** xref:guide/intro.adoc[Introduction]
```

**Docusaurus (`sidebars.ts`):**

```typescript
import type { SidebarsConfig } from "@docusaurus/plugin-content-docs";

const sidebars: SidebarsConfig = {
  tutorialSidebar: [
    "index",
    {
      type: "category",
      label: "Getting Started",
      items: ["guide/intro"],
    },
  ],
};

export default sidebars;
```

_(Alternatively, you can enable auto-generated sidebar panels in Docusaurus by setting `type: 'autogenerated', dirName: '.'` to automatically mirror your folder structure)._

## Conversion of your AsciiDoc

To automate the conversion of your AsciiDoc (`.adoc`) files to Markdown (`.md` / `.mdx`) for Docusaurus, you can use a Node.js script that processes files recursively, strips out Antora-specific headers, and converts basic syntax elements using regular expressions.

Below is a robust Node.js script using the native `fs` and `path` modules. It handles recursive directory traversal, rewrites extension links (`.adoc` to `.md`), and translates common Antora/AsciiDoc constructs (admonitions, titles, code blocks, and cross-references) into standard Markdown.

### Node.js Conversion Script (`convert-adoc.js`)

````javascript
const fs = require("fs");
const path = require("path");

// Configure your source (Antora modules/ROOT/pages) and destination (Docusaurus docs) folders
const SOURCE_DIR = path.join(__dirname, "antora-content");
const TARGET_DIR = path.join(__dirname, "docusaurus-docs");

function convertAdocToMarkdown(content) {
  // 1. Convert AsciiDoc title (= Title) to Markdown (# Title)
  content = content.replace(/^=\s+(.+)$/gm, "# $1");

  // 2. Convert headings (== Title -> ## Title, === Title -> ### Title, etc.)
  content = content.replace(/^(={2,6})\s+(.+)$/gm, (match, equals, title) => {
    const level = equals.length;
    return `${"#".repeat(level)} ${title}`;
  });

  // 3. Convert Admonitions (NOTE:, WARNING:, TIP:, IMPORTANT:, CAUTION:)
  // Antora: NOTE: This is a note.
  // Docusaurus: :::note\nThis is a note.\n:::
  const admonitions = ["NOTE", "WARNING", "TIP", "IMPORTANT", "CAUTION"];
  admonitions.forEach((adm) => {
    const regex = new RegExp(`^${adm}:\\s+(.*)$`, "gm");
    content = content.replace(regex, `:::${adm.toLowerCase()}\n$1\n:::`);
  });

  // 4. Convert source code blocks
  // Antora: [source,python]\n----\nprint("hello")\n----
  // Markdown: ```python\nprint("hello")\n```
  content = content.replace(
    /\[source,\s*([a-zA-Z0-9_-]+)\]\s*\n?-{4,}\s*\n([\s\S]*?)\n?-{4,}/g,
    "```$1\n$2\n```",
  );

  // Generic unlabelled code blocks (----)
  content = content.replace(/-{4,}\s*\n([\s\S]*?)\n?-{4,}/g, "```\n$1\n```");

  // 5. Convert Cross-References and Links
  // Antora: xref:page-name.adoc[Link Text] -> [Link Text](./page-name.md)
  // Antora: xref:page-name.adoc[] -> [page-name](./page-name.md)
  content = content.replace(
    /xref:([a-zA-Z0-9_\-\./]+)\.adoc\[(.*?)\]/g,
    (match, linkPath, label) => {
      const cleanLabel = label.trim() || path.basename(linkPath);
      return `[${cleanLabel}](./${linkPath}.md)`;
    },
  );

  // Standard external/internal links: https://example.com[Label] -> [Label](https://example.com)
  content = content.replace(/([hH]ttps?:\/\/[^\s\[]+)\[(.*?)\]/g, "[$2]($1)");

  // 6. Convert formatting (bold, italic)
  // *bold* -> **bold** (Be careful not to mess up unordered lists, so target text inside spaces or punctuation)
  content = content.replace(/(^|\s)\*([^\*\n]+)\*(\s|$)/g, "$1**$2**$3");
  content = content.replace(/(^|\s)_([^_\n]+)_(\s|$)/g, "$1*$2*$3");

  return content;
}

function processDirectory(src, dest) {
  if (!fs.existsSync(dest)) {
    fs.mkdirSync(dest, { recursive: true });
  }

  const entries = fs.readdirSync(src, { withFileTypes: true });

  for (let entry of entries) {
    const srcPath = path.join(src, entry.name);

    if (entry.isDirectory()) {
      // Skip hidden folders like .git or Antora module scaffolding if needed
      if (entry.name.startsWith(".")) continue;
      processDirectory(srcPath, path.join(dest, entry.name));
    } else if (entry.isFile() && path.extname(entry.name) === ".adoc") {
      const fileName = path.basename(entry.name, ".adoc") + ".md";
      const destPath = path.join(dest, fileName);

      let fileContent = fs.readFileSync(srcPath, "utf8");

      // Strip Antora specific attributes header if present (e.g., :page-layout: etc.)
      fileContent = fileContent.replace(/^:[a-zA-Z0-9_\-]+:.*$/gm, "");

      const convertedContent = convertAdocToMarkdown(fileContent);

      fs.writeFileSync(destPath, convertedContent, "utf8");
      console.log(`Converted: ${srcPath} -> ${destPath}`);
    }
  }
}

// Run the migration
console.log("Starting AsciiDoc to Markdown conversion...");
processDirectory(SOURCE_DIR, TARGET_DIR);
console.log("Conversion complete!");
````

### How to Use It:

1. Initialize a temporary node script file:

```bash
npm init -y
touch convert-adoc.js
```

2. Paste the code above into `convert-adoc.js`.
3. Adjust `SOURCE_DIR` and `TARGET_DIR` variables at the top of the script to point to your Antora source folder (e.g., your component's `modules/ROOT/pages`) and your target Docusaurus `docs/` folder.
4. Run the script:

```bash
node convert-adoc.js
```
