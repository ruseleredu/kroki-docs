Third Party Tools

A list of third party tools, developed by the community, that rely on Kroki.

Decoders​

The following tools help with decoding an encoded (deflate + base64) diagram e.g. as found in Kroki log messages.

Kroki Encoder / Decoder​

JavaScript app for the browser to decode Kroki URLs back into code by Philipp C. Baecker. No backend required.

IntelliJ AsciiDoc Plugin​

A plugin for the IntelliJ platform (IntelliJ IDEA, RubyMine, etc.) that provides support for the AsciiDoc markup language. The preview supports rendering diagrams using Kroki.

KeenWrite​

A Java-based desktop text editor with live preview, string interpolation, and formulas.

Niolesk​

An online editor for Kroki.

💡 TIP

Add any Kroki URL after https://niolesk.top/# and you’ll be able to edit your diagram.

Here’s an example: https://niolesk.top/#https://kroki.io/plantuml/svg/eNpTLMlIzU1VyM3MK6nk4nLKT9K1c8zJTE61UvBIzcnJVwQArksKZQ==

Kroki Editor​

A self-hostable web editor for Kroki, with live preview, syntax highlighting, an examples gallery, and shareable image URLs.

Visual Studio Code​

The following Visual Studio Code plugins support Kroki:

  • AsciiDoc
  • AsciiDoc Slides
  • Markdown Kroki

GitLab​

GitLab can use Kroki to render images in Markdown, AsciiDoc, reST and Textile documents.

Sphinx Documentation​

There is an Kroki integration for the Sphinx documentation generator.

Julia​

The Kroki.jl package provides integrations for the Julia programming language. It enables rendering diagrams in environments such as Documenter.jl, Pluto notebooks and Julia’s Visual Studio Code integration.

MkDocs​

The MkDocs Kroki plugin embeds Kroki diagrams within Markdown files processed by MkDocs.

Jekyll​

The Jekyll Kroki plugin embeds Kroki diagrams within Markdown files processed by Jekyll.

Remark​

The Remark Kroki plugin embeds Kroki diagrams within Markdown files processed by Remark.

HugoMods​

The Hugo Kroki module embeds Kroki diagrams within Markdown files processed by Hugo.

Python-Markdown​

The Python-Markdown Kroki extension embeds Kroki diagrams within Markdown files processed by Python-Markdown. It supports Python-Markdown based applications such as MkDocs and Pelican.

Mediawiki​

There is a MediaWiki Kroki extension. This way you can easily integrate diagrams into wiki pages while benefiting from revision control for those diagrams.
