# Install Kroki

This section covers installing Kroki locally.

On this page, you’ll learn:

- [x] How to get started
- [x] The different ways to install Kroki
- [x] About the Kroki pre-built image containers and the diagrams they provide

## Get started

Use either Docker or Podman as the easiest and fastest method to get started running Kroki locally on a system with Internet access using the pre-built Kroki containers published on Docker Hub.

Start the mandatory `yuzutech/kroki` container only to use a large number of diagram libraries immediately including PlantUML, GraphViz and more.
Depending on your diagram needs, this may be enough.

For the lists of diagram libraries pre-installed in each container see the [Kroki container images](#kroki-container-images) section on this page.

**📌 NOTE**\
All the companion containers are _optional_.
Only the yuzutech-kroki container is mandatory.

## Kubernetes

Find how to make a Kubernetes installation on the [use-kubernetes.mdx](use-kubernetes.mdx) page.

## Manual installation

You can also make a customized manual installation that suits your needs.

To do this, you will need to manually install the Kroki gateway server as a _standalone executable jar_, install each diagram library that you want to use, then run the gateway server jar file.

You are responsible for managing diagram library installations on your system.

Find how to make a manual installation on the [Manual installation](manual-install.mdx) page.

## Kroki container images

Kroki container images are published on the [Docker Hub](https://hub.docker.com/u/yuzutech) registry and are the:

- Mandatory ["kroki" container](#The "kroki" container) that provides the gateway server and a large number of diagrams.
- _Optional_ [companion containers](#companion-containers) that provide additional diagrams.
  Please note that you need the gateway server to interact with them.

## The "kroki" container

The `yuzutech/kroki` container is the only container that must be running for a minimal install.

The [yuzutech/kroki](https://hub.docker.com/r/yuzutech/kroki) image contains the gateway server, and the following diagram libraries out-of-the-box:

- [ActDiag](http://blockdiag.com/en/actdiag/index.html)
- [BlockDiag](http://blockdiag.com/en/blockdiag/index.html)
- [Bytefield](https://bytefield-svg.deepsymmetry.org/)
- [D2](https://github.com/terrastruct/d2)
- [Ditaa](http://ditaa.sourceforge.net)
- [Erd](https://github.com/BurntSushi/erd)
- [GoAT](https://github.com/blampe/goat/)
- [GraphViz](https://www.graphviz.org/)
- [Nomnoml](https://github.com/skanaar/nomnoml)
- [NwDiag](http://blockdiag.com/en/nwdiag/index.html)
- [PacketDiag](http://blockdiag.com/en/nwdiag/packetdiag-examples.html)
- [Pikchr](https://github.com/drhsqlite/pikchr)
- [PlantUML](https://github.com/plantuml/plantuml) including [C4 model](https://github.com/RicardoNiepel/C4-PlantUML)
- [RackDiag](http://blockdiag.com/en/nwdiag/rackdiag-examples.html)
- [SeqDiag](http://blockdiag.com/en/seqdiag/index.html)
- [Structurizr](https://github.com/structurizr/dsl)
- [Svgbob](https://github.com/ivanceras/svgbob)
- [Symbolator](https://github.com/hdl/symbolator)
- [UMlet](https://github.com/umlet/umlet)
- [Vega](https://github.com/vega/vega)
- [Vega-Lite](https://github.com/vega/vega-lite)
- [WaveDrom](https://wavedrom.com)
- [WireViz](https://github.com/formatc1702/WireViz)

## Companion containers

These optional companion containers provide additional diagrams and require the gateway server

- **[yuzutech/kroki-bpmn](https://hub.docker.com/r/yuzutech/kroki-bpmn)**\
  Provides BPMN diagrams for Kroki using the [bpmn-js](https://bpmn.io/toolkit/bpmn-js/) library.

- **[yuzutech/kroki-excalidraw](https://hub.docker.com/r/yuzutech/kroki-excalidraw)**\
  Provides hand-drawn diagrams for Kroki using the [Excalidraw](https://excalidraw.com/) library.

- **[yuzutech/kroki-mermaid](https://hub.docker.com/r/yuzutech/kroki-mermaid)**\
  Provides flowchart, sequence and Gantt diagrams for Kroki using the [Mermaid](https://mermaidjs.github.io/) library.

- **[yuzutech/kroki-diagramsnet](https://hub.docker.com/r/yuzutech/kroki-diagramsnet) (experimental)**\
  Provides diagrams for Kroki using the [diagrams.net](https://diagrams.net/) library.
