# Third Party Tools

A list of third party tools, developed by the community, that rely on Kroki.

## Decoders

The following tools help with decoding an encoded (deflate + base64) diagram e.g. as found in Kroki log messages.

### Kroki Encoder / Decoder

[JavaScript app for the browser](https://kroki.pcbaecker.com/) to decode Kroki URLs back into code [by Philipp C. Baecker](https://www.pcbaecker.com/articles/kroki-encoder-decoder/). No backend required.

## IntelliJ AsciiDoc Plugin

[A plugin for the IntelliJ platform](https://github.com/asciidoctor/asciidoctor-intellij-plugin) (IntelliJ IDEA, RubyMine, etc.) that provides support for the AsciiDoc markup language.
The preview supports rendering diagrams using Kroki.

## KeenWrite

[A Java-based desktop text editor](https://keenwrite.com) with live preview, string interpolation, and formulas.

## Niolesk

[An online editor](https://niolesk.top) for Kroki.

<dl>
  <dt>
    <strong>💡 TIP</strong>
  </dt>
</dl>

Add any Kroki URL after `https://niolesk.top/#` and you’ll be able to edit your diagram.

Here’s an example: https://niolesk.top/#https://kroki.io/plantuml/svg/eNpTLMlIzU1VyM3MK6nk4nLKT9K1c8zJTE61UvBIzcnJVwQArksKZQ==

## Kroki Editor

[A self-hostable web editor](https://github.com/yoyoys/kroki-editor) for Kroki, with live preview, syntax highlighting, an examples gallery, and shareable image URLs.

## Visual Studio Code

The following [Visual Studio Code](https://code.visualstudio.com) plugins support Kroki:

- [AsciiDoc](https://marketplace.visualstudio.com/items?itemName=asciidoctor.asciidoctor-vscode)
- [AsciiDoc Slides](https://marketplace.visualstudio.com/items?itemName=flobilosaurus.vscode-asciidoc-slides)
- [Markdown Kroki](https://marketplace.visualstudio.com/items?itemName=pomdtr.markdown-kroki)

## GitLab

[GitLab](https://about.gitlab.com) can [use Kroki to render images](https://docs.gitlab.com/ce/administration/integration/kroki.html) in Markdown, AsciiDoc, reST and Textile documents.

## Sphinx Documentation

There is an [Kroki integration](https://github.com/sphinx-contrib/kroki) for the [Sphinx documentation generator](https://www.sphinx-doc.org).

## Julia

The [Kroki.jl](https://bauglir.github.io/Kroki.jl/stable) package provides integrations for the [Julia programming language](https://julialang.org).
It enables rendering diagrams in environments such as [Documenter.jl](https://juliadocs.github.io/Documenter.jl/stable), [Pluto notebooks](https://github.com/fonsp/Pluto.jl) and Julia’s [Visual Studio Code integration](https://www.julia-vscode.org).

## MkDocs

The [MkDocs Kroki plugin](https://pypi.org/project/mkdocs-kroki-plugin) embeds Kroki diagrams within Markdown files processed by MkDocs.

## Jekyll

The [Jekyll Kroki plugin](https://rubygems.org/gems/jekyll-kroki) embeds Kroki diagrams within Markdown files processed by Jekyll.

## Remark

The [Remark Kroki plugin](https://github.com/nice-move/remark-kroki) embeds Kroki diagrams within Markdown files processed by Remark.

## HugoMods

The [Hugo Kroki module](https://kroki.hugomods.com/) embeds Kroki diagrams within Markdown files processed by Hugo.

## Python-Markdown

The [Python-Markdown Kroki extension](https://hkato.github.io/markdown-kroki/) embeds Kroki diagrams within Markdown files processed by [Python-Markdown](https://python-markdown.github.io/). It supports Python-Markdown based applications such as [MkDocs](https://www.mkdocs.org/) and [Pelican](https://getpelican.com/).

## Mediawiki

There is a [MediaWiki Kroki extension](https://www.mediawiki.org/wiki/Extension:Kroki). This way you can easily integrate diagrams into wiki pages while benefiting from revision control for those diagrams.
