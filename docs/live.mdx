# Live Editor

---

## 🛠 General-Purpose & Multi-Paradigm

- **Mermaid** – Markdown-inspired syntax for flowcharts, sequence diagrams, and charts.
- **PlantUML** – Text-based UML and system architecture diagrams.
- **Graphviz / DOT** – Graph visualization using the DOT language.
- **D2** – Declarative diagram scripting language.
- **Diagrams.net** – Open-source diagram editor (Draw.io engine).
- **Excalidraw** – Virtual whiteboard for sketch-style diagrams.
- **UMlet** – Interactive UML diagram drawing tool.
- **TikZ** – Programmatic graphics package for LaTeX.

---

## 🏛 Software Architecture & Modeling

- **C4PlantUML** – PlantUML macros for the C4 architecture model.
- **Structurizr** – Visualizing/documenting software architecture with C4.
- **Nomnoml** – Lightweight UML class diagram tool.

---

## 🌐 Network, Infrastructure & Layouts

- **BlockDiag** – Block diagram generator.
- **ActDiag** – Activity diagram generator.
- **NwDiag** – Network diagram generator.
- **RackDiag** – Server rack layout diagrams.
- **PacketDiag** – Network packet structure diagrams.
- **SeqDiag** – Sequence diagram generator.
- **WireViz** – Cable/wiring harness documentation tool.

---

## 🗄 Databases & Entity Relationships

- **DBML** – Database schema definition language.
- **ERD** – Entity-Relationship diagram generator.

---

## ⚙️ Hardware, Timing & Protocols

- **WaveDrom** – JSON-based digital timing diagrams.
- **Bytefield** – Protocol/memory layout packet diagrams.
- **Symbolator** – HDL schematic symbol generator.

---

## 📊 Data Visualization

- **Vega** – Declarative interactive visualization grammar.
- **Vega-Lite** – High-level grammar built on Vega.

---

## ✏️ ASCII Art, Text-to-SVG & Aggregators

- **Ditaa** – ASCII diagrams → vector graphics.
- **SvgBob** – ASCII diagrams → SVG.
- **Goat** – Go-based ASCII-to-SVG renderer.
- **Pikchr** – PIC-inspired markup for technical diagrams.
- **BPMN** – Business Process Model & Notation renderer.
- **Kroki** – Unified API aggregator for diagramming tools.
